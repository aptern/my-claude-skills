# yandex-webmaster

Забирает данные из Яндекс.Вебмастера (API v4) и помогает анализировать SEO сайта **nacifrah.ru**.

## Когда использовать

Пользователь просит посмотреть состояние сайта в поиске, ошибки, позиции, индексацию, динамику — или в целом «улучшить SEO». Скилл тянет свежие данные напрямую из API; данные никуда не публикуются, используются только для анализа.

## Быстрый старт

Все скрипты лежат в `scripts/`, выводят JSON (или дайджест для `summary.sh`). Запуск из любой директории.

```bash
DIR=~/.claude/skills/yandex-webmaster/scripts

bash $DIR/summary.sh              # единый SEO-срез (начинай отсюда)
bash $DIR/check_token.sh          # валидность токена + срок
bash $DIR/hosts.sh                # список подтверждённых сайтов
```

## Скрипты

| Скрипт | Что отдаёт | Полезные флаги |
|---|---|---|
| `summary.sh` | Сводный дайджест: ИКС, проблемы, индекс, топ-запросы, ссылки | — |
| `diagnostics.sh` | Проблемы сайта | `--all` (все проверки, не только активные) |
| `search_queries.sh` | Запросы: показы/клики/CTR/позиции | `--order TOTAL_CLICKS`, `--limit N`, `--history`, `--device MOBILE`, `--from/--to` |
| `indexing.sh` | Обход (HTTP-статусы) + страницы в поиске | `--samples`, `--from/--to` |
| `excluded.sh` | События индекса (появление/выпадение) | `--removed` (только выпавшие + причина) |
| `links.sh` | Внешние ссылки: динамика + доноры | `--samples`, `--from/--to` |
| `sqi.sh` | История ИКС | `--from/--to` |
| `check_token.sh` | Валидность токена + предупреждение о сроке | — |
| `get_token.sh` | Перевыпуск OAuth-токена | `--client-id`, `--client-secret` |

Период по умолчанию — последние 30 дней. Даты в формате `YYYY-MM-DD`.

## Как анализировать (принципы)

1. **Начинай с `summary.sh`** — он даёт картину целиком, дальше углубляйся точечными скриптами.
2. **Сначала — активные проблемы** (`diagnostics.sh`): чини `FATAL` и `CRITICAL` в первую очередь, потом `POSSIBLE_PROBLEM`, в конце `RECOMMENDATION`. Расшифровка кодов — в [references/API.md](references/API.md).
3. **CTR и позиции** (`search_queries.sh`): запрос с высокими показами, низким CTR и позицией в топ-10 → проблема сниппета (title/description). Запрос с хорошим CTR, но позицией >10 → точка роста контентом/ссылками.
4. **Выпавшие страницы** (`excluded.sh --removed`): смотри `reason` (excluded_url_status) — это говорит, почему Яндекс убрал страницу.
5. **Связывай с правками сайта**: страницы и тексты живут в репозитории `my-b2b-landing`. Нашёл проблему сниппета → можно сразу предложить правку meta-тегов в коде.
6. **НЕ выдумывай данные.** Если API чего-то не отдаёт — так и скажи, не достраивай цифры (общий принцип проекта).

## Авторизация

- OAuth-токен в `config/.env` (`YANDEX_WEBMASTER_TOKEN`). Это тот же OAuth-аккаунт, что и Wordstat — приложение имеет права Вебмастера.
- `user_id` и `host_id` кэшируются в `cache/` (резолвятся автоматически по домену из `YANDEX_WEBMASTER_HOST`).
- Токен живёт ~1 год. `check_token.sh` предупредит, когда подойдёт срок; перевыпуск — `get_token.sh`.
